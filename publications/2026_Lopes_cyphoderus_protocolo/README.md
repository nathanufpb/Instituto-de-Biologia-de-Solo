## Descrição

Este repositório contém os protocolos e materiais suplementares desenvolvidos para testes de **bioindicação e ecotoxicologia** aplicados à região Neotropical, incluindo a proposta de uma nova **espécie-modelo regional** do gênero *Cyphoderus* (Collembola).
