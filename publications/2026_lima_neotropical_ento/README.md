## Descrição

Este repositório contém os arquivos do sistema **DELTA** (*Description Language for Taxonomy*) utilizados para a taxonomia codificada do gênero *Mucrosomia* (Collembola: Isotomidae). Os dados suportam a revisão bibliográfica e a descrição de novas espécies do gênero.

## Conteúdo

```
2026_lima_neotropical_ento/
├── taxonomia-delta/
│   └── mucrosomia.dtz              # Arquivo de projeto DELTA Free Editor
├── data/                           # Dados de espécimes (a preencher)
├── scripts/                        # Scripts de análise (a preencher)
└── results/                        # Figuras e tabelas (a preencher)
```

## Sistema DELTA

Os arquivos `.dtz` foram gerados com o **DELTA Free Editor**. Para abrir e editar:

1. Baixe o [DELTA Free Editor](http://www.delta-intkey.com/)
2. Abra o arquivo `mucrosomia.dtz`

As descrições codificadas foram geradas automaticamente a partir dos arquivos de caracteres e táxons, garantindo reprodutibilidade das descrições morfológicas.
